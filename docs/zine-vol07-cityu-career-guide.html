Chapter 01 · 资源地图

校内可利用的就业资源

学费不白交——学校、港府、行业机构三层资源，很多同学到毕业都没用上。以下是苍蔓学姐梳理的六条主线。

校企合作 / 实习实训活动

学校会与知名企业开展校企合作，形式类似"实习实训营"（如提到的 CPP 活动）。参与者可能获得与港企相关的短期实习经历；表现优秀者甚至被知名商场（如维港边的大型商场）直接录用。

香港银行业联会（HKIB）等行业活动

常见形式：2–3 天的活动，邀请汇丰、渣打等资深银行高管做分享或担任行业导师。

建议做法：加导师微信，主动请教职业发展经验、面试官看重的特质、面试表现技巧。一次活动建立的人脉，可能比海投 50 份简历更有用。

内地城市来港招聘会

上海、北京等各地高校 / 城市会定期来港举办人才招聘会。每年大概率会有一次，针对目标城市的顶尖企业 + 当地领导直接来分享 / 招聘。关注渠道：CISA 公众号会同步信息。

港府资助资源

学费不白交，一定要利用。以下三项均由港府出资或赞助：

  1. 内地文化交流团（一年 2 次）：类似旅游 + 社交，能认识很多朋友。
  2. 创业主题交流团（一年 2 次）：带队参访当地人社局 / 双创中心，可了解人才政策、人才补贴，认识创业者和志愿者。费用大约 500–1700 元左右，四五天行程。
  3. 港府资助的实习计划：港府赞助不同 NGO，NGO 再对接企业（华为、腾讯等）及顶尖机构（如深圳的金源资本等顶级 VC）提供实习名额。通过该渠道申请通常比自己海投更容易进入这些机构。深圳的相关活动是免费的，且包食宿。
获取渠道：CISA 群、CISA 公众号、小红书。深圳的活动免费且包食宿——没有理由不去。

校内春秋招 / 实习信息群

CISA 有专门的实习信息发放群（往年由学姐学妹维护），持续搜集各企业招聘进度。CC 公众号也会发布招聘相关贴文。校内（"阳楼"）几乎每月举办 1–2 场招聘会，分内地主题和香港主题。

真实案例：有同学在四大摊位与面试官聊天后当场被面试，直接省去笔试 / 一面 / 二面流程，当场拿到 offer 意向。

建议：一定要积极参加，哪怕只是扫码线上投递，也有机会遇到"捡漏"机会。

RA（Research Assistant）机会

入学后每学期都可以主动联系老师询问是否需要 RA，是否需要因老师而异（很多导师优先用自己带的博士生）。好处：如果被老师看重，有机会获得读博机会或更强的就业资源链接。

关于秋招节奏——时间窗口比你想象的窄得多，大厂的"抢人"从暑假就开始了。

越早投越好
滚动筛选不等截止日
—— 网申策略 · 第一原则

很多公司是"滚动筛选"，标注的截止日期不代表真实截止时间。早投更容易被录取；临近截止日期扎堆提交容易遇到系统卡顿 / 提交失败。

Chapter 02 · 时间线

秋招时间线与整体节奏

大厂 6 月就开始抢人，四大和国企稍晚。秋招岗位数量整体多于春招——春招多为秋招中被放弃 / 空出的岗位。

时间段 招聘主体
6–7 月 大厂率先启动秋招（抢人才，锁定优秀候选人）
8–11 月 第一梯队互联网公司信息集中放出，竞争也更激烈；快消行业也集中在此时间段
稍晚 四大会计师事务所、国企（国企一般不会像大厂那样早开）

春招 vs 秋招

秋招岗位数量整体更多。春招多为秋招中被放弃 / 空出的岗位（有人拿到更好 offer 后放弃了原岗位）。

实习安排没有固定模板

有人整年在一家公司实习后留用；有人换 3 个不同公司各实习 3 个月积累多元经验。可根据自身课业压力灵活安排。

关于是否参加"当年"秋招建议

强烈建议无论如何都先投一次，哪怕没有理想结果，也是一次实战演练（笔试 / 面试经验、反问面试官了解岗位需求的机会）。

金融专业：第二学期开学初才需决定是否选 Summer Term（决定是否 10 月毕业），因此第一学期有充足时间尝试当年秋招。若第一学期没投上，仍可在第二学期初申请"10 月毕业"，抓住第二年秋招。

Chapter 03 · 投递策略

网申与投递策略（重点避坑）

七条策略，每一条都是踩过坑之后的教训。核心原则：早投、记录、分层、不要 All in。

  1. 越早投越好：很多公司是"滚动筛选"，标注的截止日期不代表真实截止时间，早投更容易被录取；临近截止日期扎堆提交容易遇到系统卡顿 / 提交失败。
  2. 建立个人投递记录表（强烈建议）：记录——投递公司、岗位、投递用的简历版本、截止时间、笔试 / 面试时间。原因：面试官可能根据你投递时所写的具体内容提问，答不上来会显得"没有用心"。很多公司投递后无法再查看当时填写的内容（岗位下线后 JD 也可能看不到）。
  3. 简历不要"一份走天下"：应根据不同岗位方向准备不同版本简历，突出与该岗位相关的经历。HR 看一份简历平均可能只有 10 秒左右，量化成果 + 关键处加粗（不要全篇加粗）非常重要。
  4. 内推：小红书上可搜索大量内推码；内推码不保证录取，但能保证 HR 至少认真看一眼简历（避免被系统海量简历淹没）。
  5. 代投简历：不建议。机构 / 个人代投可能不及时处理，容易错过时间窗口。
  6. 多层次投递（避免"只投好岗位 / 好城市"）：建议按"保底 / 稳妥 / 冲刺"分层投递——保底：户籍所在地公司（很多企业看重稳定性 / 是否本地人）；稳妥：其他有把握的城市和岗位；冲刺：热门城市 / 热门岗位（如投研、战略岗竞争极大）。不要 All in 单一城市，热门城市（成都、重庆、北京、上海、武汉、深圳）竞争激烈。
  7. 暑期留用实习的风险：留用答辩可能被无限期推迟，导致一边实习一边到处飞面试，非常辛苦，要提前评估风险。

Chapter 04 · 简历

简历撰写要点

HR 看一份简历平均 3–10 秒。STAR 法则 + 量化成果 + 关键处加粗，是过简历关的基本功。

STAR 法则

Situation（情景）→ Task（任务）→ Action（行动）→ Result（结果）。结果一定要量化，避免"产出一篇研报"这种泛化表述，应写清围绕什么主题、多少字。

香港简历特别注意

项目 要求
照片不要放（香港重视隐私，放照片可能起反效果）
生日不要写
性别不要写
语言用英文书写（哪怕是香港 local 公司，工作语言也是英语）
邮箱用 Gmail（不要用 163 / QQ 邮箱）
电话用香港本地号码
联系方式必须留清晰联系方式（电话 + 邮箱），否则 HR 联系你需要额外花费平台"额度"

排版与其他

字体 / 排版要简洁清晰，避免花哨字体和杂乱排版（HR 3–10 秒扫一眼，乱了直接被跳过）。数字 / 成果不要用中文描述数字（不利于突出量化效果）。小公司实习也算数，只要有可量化、可独立完成的产出。

反面教材："产出一篇研报"——太泛了。
正确写法："围绕粤港澳大湾区消费升级主题，独立完成 8000 字行业研报，被导师选为课程示范案例。"

Chapter 05 · Cover Letter

Cover Letter 结构（多用于外企）

Cover Letter 不是简历的重复，而是"为什么是我"的论证。三步准备法 + 三段结构。

三步准备法

  1. 研究公司（官网 / 领英建联该公司员工，约 Coffee Chat）；
  2. 分析职位描述（JD），明确职责与所需资质；
  3. 回顾自身背景与岗位的匹配度。

三段结构

开头：说明申请原因 → 主体段落：突出与岗位相关的核心能力 / 优势 → 结尾：感谢阅读 + 联系方式。

关于 Coffee Chat 建联

外企 / 香港 local 公司 / 外国人通常更愿意接受 Coffee Chat 请求；中资大厂（字节、腾讯、华为等）的人普遍太忙，很少回复领英建联请求。

Chapter 07 · 面试

面试相关

三轮面试各有侧重：HR 面看诚意，业务面看专业，终面看格局。无领导小组和结构化面试各有解法。

面试轮次

  1. 一面（HR 面）：偏泛面，考察对公司 / 岗位的基本了解、是否海投缺乏诚意等，时长通常较短、多为线上 1v1。
  2. 二面（业务面）：由业务负责人 / 未来 Mentor 主导，专业深度考察更强，时长更长。可能是 1v1、1v多或无领导小组。
  3. 三面（终面）：一般是较高 level 的人来面，进入终面后拿到 offer 的概率相对较大。

无领导小组面试

常见形式：选择排序题、辩论题、谈判题（较少见）、脱敏业务案例讨论。

角色选择：Leader / Timer / Note-taker / 总结陈述者等，根据自身优势选择角色，不必抢 Leader（表现不好反而扣分）。

结构化 / 半结构化面试

提前拆解目标岗位 JD 关键词，简历和回答尽量向 JD 描述的能力 / 问题靠拢。常见问题：为什么选择这个行业 / 公司 / 岗位？不是本地人为何选择这个城市？对行业的了解？财务分析能力（投研类岗位）等。

建议提前准备"模板化"的经历回答，并可与 AI 模拟对话练习（自己回答后，让 AI 扮演 HR 追问）。

感谢信

非必须，但有实际案例：某候选人因为坚持写感谢信，在原本未通过的情况下，后续岗位空缺时被优先考虑并拿到 offer。

Chapter 08 · 踩坑总结

学姐秋招踩坑经验总结

非常实用，建议重点参考。八条踩坑 + 四条做对了的事——每一条都是真金白银换来的教训。

八条踩坑

  1. 起步太晚：没有从 8 月初开始投递，错过大量大厂 6–7 月的滚动招聘窗口。
  2. 低估竞争难度：某广东头部国企管培岗位报录比约 350:1；中银某年网申简历编号到 36 万。
  3. 只投好岗位 / 好方向，没有分层次投递：只投总行、国际总部、投研 / 战略岗，导致很多简历关都过不了，进终面的机会少。
  4. 忽视户籍所在地优势：面试某央企子公司战略投资岗时，自我介绍后第一个问题就是"是不是本地人 / 是不是党员"，答案不理想直接 5 分钟结束面试。
  5. 简历改得太晚：秋招已经进行一段时间才匆忙找老师改简历。
  6. 暑期留用实习拖延转正答辩，导致边实习边全国飞面试，非常辛苦。
  7. All in 单一城市 / 地区，导致颗粒无收；后来发现成都、重庆、北京、上海、武汉、深圳等竞争都非常激烈。
  8. 未及时记录截止时间，容易错过笔试 / 面试机会。

做得好的地方

边秋招边刷小红书，及时了解行业动态（如：券商 / 基金秋招很多只发"差额实习转正"名额），据此及时调整主投方向（如改投国企、银行）。

使用"塔塔网申"插件辅助批量网申（浏览器插件，不用开 VPN），节省填写时间。不建议找人代投简历，容易延误时机。

海投基数：该学姐海投了 300+ 份简历；建议不要因挑剔而只投十几份，基数太小基本很难成功。

Chapter 09 · 薪资市场

薪资与岗位市场参考

香港应届生薪资多数在 1.5 万–2 万港币区间。PE/VC 在收缩，行研不多不少。

  • ▸ 香港应届生薪资：多数在 1.5 万–2 万港币左右，2 万算是较好水平。
  • ▸ PE / VC 岗位：竞争一直很激烈，且近期行业在收缩（经济形势影响，相关公司已有裁员），扩张招聘的机会更少。
  • ▸ 行研岗位：不算稀缺但也不算多，多见于券商及研究类机构。

Chapter 12 · 社交人脉

社交与人脉资源

以金融专业为例，可迁移到其他专业。校友群、联合讲座、行业峰会——人脉不是"认识谁"，而是"谁知道你在找什么"。

  • ▸ 各专业有自己的校友群（含往届学长学姐），常有内部实习 / 招聘信息、各城市校友会聚会信息。加分享人微信备注专业可拉入相关校友群。
  • ▸ 学校常与其他高校（如复旦）联合举办讲座，可拓展人脉。
  • ▸ 学校也会对接大型行业峰会的志愿者名额 / 免费门票（例：往年争取过 Fintech Week 的免费门票，原价约 499 美金，凭 CFA 等身份免费获取）。
Stephanie 老师分享的求职理念：不要自我设限——曾有学生通过银行官网名单，逐一线下拜访各银行网点争取实习机会并成功拿到 offer。同时建议多阅读英文新闻，拓宽信息来源，不被语言限制视野。

  • 建立"投递记录表"（公司 / 岗位 / 简历版本 / 截止时间 / 笔面试时间）
